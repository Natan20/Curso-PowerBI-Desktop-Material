# Microsoft Power BI Desktop — Material do Curso

Material de apoio da disciplina **Microsoft Power BI Desktop**, do curso **Assistente em Análise de Dados** (Turma 103788). Aqui você encontra, para cada aula: a apostila (ou guia, nas aulas 14 e 15), os slides usados em sala e as bases de dados de exemplo.

**Carga horária:** 60h (15 aulas de 4h)
**Período:** 01/09/2026 a 08/10/2026

## Como usar

Antes de cada aula, baixe a pasta correspondente (`Aula NN - DD-MM-AAAA`). Ela já vem com tudo que você vai precisar naquele dia: apostila, slides e os arquivos de dados usados na prática.
